# ana-portfolio

**Aluna:** Ana Lucia Weber Cattani – Engenharia de Software, UTFPR Dois Vizinhos

**Site publicado:** https://anawebcatt.github.io/ana-portfolio/

## Etapas

Cada etapa do trabalho fica numa pasta própria, com uma cópia completa do site:

| Pasta | Etapa | Site |
|---|---|---|
| [`01-html-puro/`](01-html-puro/) | Primeira versão do site usando somente HTML (sem CSS, frameworks ou JavaScript), com foco na estrutura correta do documento: títulos, parágrafos, links, imagem, navegação entre seções e formulário de contato. | https://anawebcatt.github.io/ana-portfolio/01-html-puro/ |
| [`02-css/`](02-css/) | Transformação visual da mesma página com um arquivo CSS externo ([`02-css/css/style.css`](02-css/css/style.css)), separando conteúdo/estrutura de apresentação: cores, tipografia, espaçamentos, bordas, tamanhos, estilização de links e do formulário, organização das seções e estados de hover. | https://anawebcatt.github.io/ana-portfolio/02-css/ |
